# Amaze Dex

This repository contains the MuJoCo XML simulation files for the scripts and all assets files in asset subfolder



## File Structure

* **`robot.xml`**: Primary xml that contain hand description  
* **`scene.xml`**: It contains complete setup with cube and stand  
* **`rock.xml`**: It contains complete hand and stand only
* **`joint_properties`**: Contains all joint properties   
* **`tag36hll_XX.png`**: Aruco tags placed on the cube  
* **`assets`**: Contains all the stl files
